# Phantom Line

A haunted-railway tower defense in 3D. Every night at 12:13 a ghost train pulls into Hollow Vale. Line the tracks with lanterns, bells, salt mortars and prisms, and don't let its passengers reach the station.

**Play:** https://games.getsimpleinvoice.app/phantom-line/

## 10 lines (levels)
1. Foggy Platform: wisps, learn the lantern
2. Moonlit Junction: fast banshees, Bell tower unlocked
3. Graveyard Siding: phasing shades, Salt Mortar unlocked
4. Frozen Viaduct: armoured Conductors, Prism unlocked
5. Mine Tunnel: first Phantom Carriage boss
6. Swamp Trestle: wisp swarms
7. Clocktower Yard: Conductor marches
8. Blood Moon Line: everything at once, faster
9. Storm Bridge: two Phantom Carriages
10. The Last Terminus: the longest track and three bosses

Each line has its own track layout, palette, fog and scenery. Waves get longer and ghosts get tougher as you go.

## Towers
| Tower | Role |
|---|---|
| 🏮 Lantern | Cheap, fast single-target beam (half damage vs Conductors) |
| 🔔 Bell | Pulse that damages and slows everything nearby |
| 🧂 Salt Mortar | Long-range arcing splash |
| 🔮 Prism | Beam that chains between ghosts |

Each tower upgrades twice. Selling refunds 70%. Calling a wave early earns bonus coins.

## Controls
| Action | Keyboard | Mouse / Touch |
|---|---|---|
| Build / select tower | Arrows/WASD + Space/Enter | Click / tap a tile |
| Choose tower type | 1–4 | Bottom bar |
| Upgrade / Sell | U / X | Tower panel |
| Next wave | N | 🚂 Wave |
| Rotate camera | Q / E | ⟳ |
| Fast forward | F | ⏩ |
| Pause / Mute | P or Esc / M | ⏸ / ♪ |
