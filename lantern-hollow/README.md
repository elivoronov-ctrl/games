# Lantern Hollow

Catch fireflies in a moonlit meadow and carry them to the Great Lamp to keep the long night away, alongside other lantern-bearers online.

**Play:** https://games.getsimpleinvoice.app/lantern-hollow/

## Progression
- **5 nights**: First Glimmer, Pond Song (frogs), Whistling Wind (gusts), Owl Moon (diving owls), Starfall (golden swarms). Each night the Lamp needs a glow goal, or it goes dark.
- **XP levels**: banked glow is XP. Each level-up offers 1 of 3 upgrades (Swift Boots, Wide Net, Big Lantern, Honey Glow magnet, Wind Step dash, Moth Ward, Lamp Song bonus), up to 5 ranks each.
- **Lantern colors** unlock at levels 3, 6 and 9, plus a white lantern for reaching dawn (saved locally).
- Fireflies: green (1), blue and fast (2), gold and rare (5). Moths steal from your lantern, frogs lash out from lily pads, owls swoop.

## Controls
| Action | Keyboard | Mouse / Touch |
|---|---|---|
| Move | WASD / Arrows | Hold the mouse button toward a spot / left stick |
| Dash (scares moths, dodges owls) | Space | DASH button |
| Pick upgrade | 1 / 2 / 3 | Tap a card |
| Pause / Mute | P or Esc / M | ⏸ / ♪ buttons |

## Multiplayer
Enter a name and you join the shared hollow automatically (Supabase Realtime broadcast + presence, no accounts). You see other players' lanterns live, an online count and a glow leaderboard. When someone banks at the Lamp, everyone sees it, and banking while another player is near the Lamp gives a +25% together bonus. If the connection fails, the game plays solo.

Canvas 2D + Web Audio, all procedural.
